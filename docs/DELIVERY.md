# Delivery and demonstration

## Public package
- Playable Tidepost at the repository's GitHub Pages URL if repository-scoped permissions permit.
- Source with MIT license, concise readme, exact game rules, test commands and local run instructions.
- Reproducible release ZIP and SHA-256, including the built application and source.
- Accessible presentation.html with five sections styled as slides, keyboard navigation and a print layout.
- demo.html with the real application walkthrough and a downloadable recorded clip when browser recording is available.

## Demo storyboard, approximately 75 seconds
1. 0–8s. Open the real playable map. Caption: Three letters. One changing tide. No rush.
2. 8–20s. Deliver the first envelope to Tern House. Show the delivered stamp and updated tide.
3. 20–35s. Highlight the forecast and a closed route. Wait one turn and cross when it opens. Explain that only actions advance time.
4. 35–55s. Deliver the remaining letters and return to the post office through the actual game controls.
5. 55–65s. Show the completed postcard with the real route and turn count. Download the SVG.
6. 65–75s. Open a later round to show the richer route choices. End with the playable URL, not a fictional score or staged success screen.

## Five-slide presentation
1. The idea. A five-minute postal puzzle that makes waiting part of the solution.
2. The design. Paper, sea glass, readable tide forecasts and forgiving play.
3. The real experience. Three deliveries, homecoming, a route postcard.
4. Under the surface. Deterministic engine, independent solver, keyboard/mobile checks and zero runtime services.
5. The finish. Actual public links and verified constraints. Six rounds, not a procedural platform.
